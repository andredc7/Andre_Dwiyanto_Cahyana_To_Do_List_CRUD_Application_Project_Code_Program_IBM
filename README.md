## Description
Aplikasi To‑Do List sederhana namun rapi yang dibuat dengan vanilla HTML, CSS, dan JavaScript. Aplikasi ini mendemonstrasikan kemampuan CRUD (Create, Read, Update, Delete) lengkap dengan penyimpanan lokal (localStorage), antarmuka responsif, dan pengalaman pengguna yang bersih sehingga cocok dimasukkan ke portofolio.

## Technologies used
- HTML5
- CSS3 (Flexbox / Grid)
- JavaScript (ES6+)
- localStorage (Web API)
- Optional: Netlify / Vercel / Firebase Hosting untuk deployment

## Features
- Tambah tugas (Create)
- Lihat daftar tugas (Read)
- Edit tugas (Update)
- Hapus tugas (Delete)
- Tandai tugas selesai / belum
- Simpan otomatis di localStorage
- Pencarian dan filter (Selesai / Belum)
- Responsif untuk mobile dan desktop
- Button untuk menyalin daftar tugas (opsional)

## Deployment
- Netlify: drag & drop folder `Andre_DC_Portfolio` ke Netlify, atau connect repo GitHub -> Deploy. Setelah deploy, salin URL seperti `https://<projectname>.netlify.app`.
(Docs: https://docs.netlify.com/deploy/deploy-overview/)
- Vercel: Import project dari Git provider -> Deploy. URL: `https://<projectname>.vercel.app`.
(Docs: https://vercel.com/docs/deployments/generated-urls)
- Firebase Hosting: `firebase init hosting` dan `firebase deploy`. URL: `https://<project-id>.web.app`.
(Docs: https://firebase.google.com/docs/hosting)

Selama pengembangan, AI digunakan sebagai alat bantu untuk:

- Memberi rekomendasi UI/UX dan pola penyimpanan,
- Menyediakan contoh kode dan refaktor.
Namun, semua kode akhir telah ditinjau, dimodifikasi, dan diberi komentar manual agar sesuai gaya penulisan developer asli. AI hanya berperan dalam fase asistensi, bukan sebagai autor final.
